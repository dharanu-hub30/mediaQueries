# WindWave – CSS Media Queries Breakpoints

Responsive demo page on harnessing wind energy for smart cities, using CSS media queries.

## Files (all in one flat folder)
| File | Purpose |
|------|---------|
| `windwave-turbine-home.html` | Main page |
| `windwave-turbine-styles.css` | Styles and all `@media` rules |
| `windwave-turbine-live.js` | Live width, breakpoint and orientation indicator |
| `windwave-turbine-breakpoints.svg` | Desktop / tablet / mobile breakpoint diagram |
| `vercel.json` | Tells Vercel to serve the main page at the root link (keep this exact name) |

## Deploy
Upload all 6 files to the root of a GitHub repo, then import it in Vercel (Framework Preset: Other, no build command).
