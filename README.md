# WindWave – CSS Media Queries Breakpoints

Responsive demo page on harnessing wind energy for smart cities, using CSS media queries.

## Files (all in one flat folder)
| File | Purpose |
|------|---------|
| `index.html` | Main page (keep this name for Vercel/GitHub) |
| `windwave-mq-styles.css` | Styles and all `@media` rules |
| `windwave-mq-live.js` | Live width, breakpoint and orientation indicator |
| `windwave-mq-breakpoints.svg` | Desktop / tablet / mobile breakpoint diagram |

## Run locally
Open `index.html` in a browser and resize the window.

## Deploy
Upload all 5 files to the root of a GitHub repo, then import it in Vercel (Framework Preset: Other, no build command).
